# Tugas UTS Pemrograman - Studypoint (Bahasa C & Python)

Repositori ini berisi dokumentasi berupa tangkapan layar (*screenshot*) kode program dan hasil eksekusi terminal untuk memenuhi tugas Ujian Tengah Semester (UTS).

## Tentang Program (Studypoint)
**Studypoint** adalah program kalkulator sederhana untuk menghitung total nilai, rata-rata, dan persentase peluang pencapaian target belajar siswa berdasarkan komponen nilai **Tugas**, **UTS**, dan **ATS**.

Program ini diimplementasikan dalam dua bahasa pemrograman:
1. **Bahasa C (`studypoint.c`)**
2. **Bahasa Python**

## Daftar Gambar yang Diunggah
**
** Menampilkan struktur kode dalam bahasa C beserta hasil uji coba perhitungan nilai di terminal.
** 
** Menampilkan struktur kode dalam bahasa Python beserta hasil uji coba perhitungan nilai di terminal.

## Fitur Utama Program
* Input nama siswa, nilai tugas, nilai UTS, nilai ATS, dan target nilai yang ingin dicapai.
* Menghitung total nilai, rata-rata dari ketiga komponen, serta persentase peluang mencapai target.
* Memberikan evaluasi atau pesan motivasi otomatis berdasarkan target nilai yang dimasukkan (menggunakan percabangan `if-else`).
